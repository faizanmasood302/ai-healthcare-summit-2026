# AI & Healthcare Summit 2026 - Inaugural Ceremony & Tilawat Experience

An interactive, ceremonial presentation and audio-visual stage application built for the **AI & Healthcare Summit 2026** hosted at Sindh Madressatul Islam University (SMIU).

The application features:
- **Interactive Ceremonial Stage**: Grand curtain unveilings, ambient lighting, floating stardust, and celebratory audio chimes.
- **Tilawat-e-Quran Segment**: Synchronized Arabic recitation (Surah Ash-Shu'ara, Ayats 79–80) with English and Urdu translations and audio narration.
- **Event Showcase**: Highlighting key themes including Stress Resilience, Mental Well-Being, and Metabolic & Diabetes Care for World Stress Awareness Day.
- **Keyboard & Click Controls**: Smooth transitions via `Space`, `Enter`, or screen click.

---

## 🚀 Quick Start

### 1. Prerequisites
- [Node.js](https://nodejs.org/) (v18.18.0 or later recommended)
- `npm`, `pnpm`, or `yarn`

### 2. Installation
Clone the repository:
```bash
git clone https://github.com/faizanmasood302/ai-healthcare-summit-2026.git
cd ai-healthcare-summit-2026
```

Install dependencies:
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to experience the ceremony.

### 4. Build for Production
```bash
npm run build
npm run start
```

## 🎯 Navigation & Stage Controls

- **Click / Space / Enter**: Progress through the stages (Welcome Screen → Unveil Curtains → Summit Poster → Tilawat Title → Starting Verse → Main Ayats → Ending Verse).
- **Direct Slide Preview**: Append `?slide=<stage>` to the URL to view specific stages directly:
  - `?slide=welcome`
  - `?slide=poster`
  - `?slide=tilawat-title`
  - `?slide=starting-verse`
  - `?slide=main-ayat`
  - `?slide=ending-verse`
